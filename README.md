# Traço

Quadro de desenho para explicar ideias, com correção de formas, camadas, imagens, atalhos e exportação PNG.

## Usar

Abra `index.html` no navegador ou publique os arquivos no GitHub Pages. Não precisa instalar dependências nem compilar.

## GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, a branch principal e a pasta `/ (root)`, e salve.

## Atalhos

- 1: selecionar; 2: desenhar; 3: círculo; 4: retângulo; 5: seta; 6: texto.
- Ctrl+Z: desfazer; Ctrl+Y: refazer; Ctrl+V: colar imagem.
- Delete: excluir selecionado; setas: mover; Shift+setas: mover 10 pixels.
- Arraste os cantos para redimensionar; Shift mantém a proporção.

Os projetos são salvos no navegador. Use Salvar projeto para baixar uma cópia editável em JSON. Cada endereço de site tem seu próprio armazenamento: para levar um projeto da prévia ao site publicado, salve o JSON e abra no novo endereço.
